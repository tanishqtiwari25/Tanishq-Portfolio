# Fixed entrance composition study

This revision starts with frame 01 of the supplied storyboard, instead of adding another camera sequence before the shot is composed. The first camera holds position; the automatic four-metre placeholder entrance motion was removed. Existing chapter navigation, reversible camera journey, project readers, education, skills and contact remain.

## Changes compared with the previous website

- Raised and shortened the LED facade so the portal has its own stage area. The source kit is batched by material; `BlenderArchitecture` clones the kit and transforms only the facade's bounded vertices. The baseline `.blend` is not regenerated by this runtime refit.
- Added a physical backstage wall, portal light, production lattice, red LED strips, side TT banners and fan placards.
- Wider entrance framing, foreground character on the actual ramp surface, and a held rear view. The name screen is now an actual WebGL canvas texture, which appears in the planar reflection. The accessible heading remains DOM text.
- Fixed the reflective ramp's reversed slope and lifted its surface above the flat modular panel tops. The reflector shader mixes its result through diffuse color, so a coated-surface metalness value is used for that particular material rather than suppressing its reflection at metalness 1.
- Shared roughness/bump maps for steel and painted hardware, irregular procedural stage haze, and existing controlled spotlights/shadows.
- Replaced the primitive crowd with alpha-tested spectator impostors: anonymous AI-generated texture atlas, 1024 square WebP, 218,636 bytes. This is a texture on separate world-space instances, not a stadium background. Desktop: 4,480 instances / 8,960 triangles / one crowd draw call. Mobile: 1,000 instances / 2,000 triangles. Their pose variation is limited to four atlas subjects, color/scale/mirroring and slight sway.

## Blender garment asset

`scripts/blender/build_entrance_performer.py` creates the original outfit study and reuses the existing animation skeleton. Output: `public/models/tt-entrance-performer.glb` (533,688 bytes), with one skinned mesh, five material primitives, 13 bones and four clips. The mesh is 7,000 vertices / 13,824 triangles, approximately 0.78 × 0.412 × 1.835 metres in Blender's X/Y/Z axes. Two packed 512-pixel fabric data maps provide roughness and normal variation.

Editable source and multi-angle material/wireframe geometry sheets are in `../performer/`. Automated game-profile QA reports no errors: no z-fighting, floating parts, inverted normals, non-manifold edges, zero-area faces or unweighted vertices. Cuff and hem near-coplanar surfaces were corrected. The sole accepted warning is stacked/tiled UV overlap: these UVs intentionally sample shared repeating fabric, and are not suitable for unique lightmap/high-to-low baking.

This is **not** a finished photorealistic likeness. The hood hides an unmodelled face. The garment silhouette, tailoring and deformation still need refinement, and the old generic walk is not a finished stair performance. The full website should not be presented as matching the reference's final visual quality.
