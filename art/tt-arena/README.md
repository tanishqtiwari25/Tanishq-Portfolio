# TT Arena Blender workflow

The editable architecture is generated by `scripts/blender/build_tt_arena.py`.
Run Blender in background mode from the portfolio root:

```powershell
& '..\tools\blender-local-runtime\SourceDir\Blender Foundation\Blender 5.2\blender.exe' --background --python scripts/blender/build_tt_arena.py
```

Outputs:

- `art/tt-arena/tt-arena.blend`: editable materials, geometry, six review cameras and the imported temporary rig/root path.
- `public/models/tt-arena-architecture.glb`: static architecture for the live website.
- `art/tt-arena/build-manifest.json`: asset metadata.

The website retains interactive project displays, ring ropes, moving lights, audio, generic animated spectators and the contact form in React/Three.js. The Blender asset supplies the stage, steel structure, terrace architecture, runway and scoreboard.

This is original procedural modelling. It is not an exact reconstruction of the reference photograph. The imported character is explicitly a development stand-in and has not passed an identity/likeness review. Final animation retargeting and likeness sculpting remain separate work.
