# TT Arena Blender workflow

The editable architecture is generated by `scripts/blender/build_tt_arena.py`.
The original architecture generator below is historical source, not a current
approved execution recipe. New Blender runs use the installed `blender-cli`
evidence runner with a reviewed, sealed plan:

```powershell
& $Python "$SkillRoot/blender-cli/scripts/run_blender.py" --blender $Blender --script scripts/blender/qa_curvature_asset.py --plan art/tt-arena/evidence/full-asset-qa.json --blend art/tt-arena/performer/curvature/tt-entrance-curvature.blend --timeout 600
```

Outputs:

- `art/tt-arena/tt-arena.blend`: editable architecture, review ring/crowd, project captures, Skills/Contact panels, six review cameras, an animated journey camera and the imported temporary rig/root path.
- `public/models/tt-arena-architecture.glb`: static architecture for the live website.
- `art/tt-arena/build-manifest.json`: asset metadata.

The website retains interactive project displays, ring ropes, moving lights, audio, generic animated spectators and the contact form in React/Three.js. The Blender asset supplies the stage, steel structure, terrace architecture, runway and scoreboard.

This is original procedural modelling. It is not an exact reconstruction of the reference photograph. The imported character is explicitly a development stand-in and has not passed an identity/likeness review. Final animation retargeting and likeness sculpting remain separate work.

The review layout is generated by `scripts/blender/complete_review.py` after the architecture GLB export. These review-only meshes do not duplicate the live interactive objects in the website. Timeline chapter markers are at frames 1, 100, 300, 480, 610 and 720.

Historical offline review images and validation metadata are in `art/tt-arena/review/`.
Re-running their scripts requires a fresh source-evidence review and sealed plan.
The walk/idle schedule is a development performance; faithful face sculpting and
final stair-climb retargeting are unfinished.

Current web composition captures are in `six-view-pass/`; their comparison sheet
places actual browser screenshots beside the supplied storyboard. These captures
are review evidence, not a photographic background used by the website.

The curvature outfit's fresh bundled QA report is
`performer/curvature/full-asset-qa.json`. Geometry/material/weight checks pass with
intentional tiling-UV and enclosed hood-opening warnings. This is not approval of
facial likeness, animation stress behaviour or final artistic quality.
